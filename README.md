# 画页存档 · Hybrid 0.7.1 预览版

**为 Windows + Chrome 制作的“轻量扩展 + 本机下载引擎”改造版。**

这不是两个仓库的直接拼接，也不是已签名的 EXE / Chrome 商店发行版。它保留 artwork-archive 的公开页面 DOM 适配与安全边界，重新实现与界面解耦的采集调度、本机持久队列和下载引擎，借鉴 XHS-Downloader 的本机协作、有限并发、下载记录及续传思路。

> **从 0.7.0 更新：先阅读 [更新与连接修复说明](UPDATE-0.7.1.md)。必须同时更新扩展和本机程序，保留原 `data` 与 `.venv`。**

> **验证范围：**已在真实 Chromium 扩展中验证配对、GET 状态读取、无勾选添加任务及本地模拟页面的解析流程；本地后端、续传、持久化及 API 验证也有测试。没有在登录米画师的 Windows Chrome 中做真实全流程验证。不承诺当前站点的全部卡片结构都能解析，也不虚报提速倍数。

## 1. Windows 安装与运行

1. 将整个压缩包解压到固定目录，例如 `D:\ArtworkArchiveHybrid`。不要直接在 ZIP 内运行，也不要放在会自动清理的临时目录。
2. 安装 **Python 3.11 或更高版本**。启动器支持已有 `.venv`、当前用户的 Python312 等常用安装路径、可选的 `py` 及 PATH 中的 Python，**不再强制依赖 Python Launcher**。官网：<https://www.python.org/downloads/windows/>。
3. 双击根目录的 **`START-WINDOWS.bat`**。
   - 第一次会创建虚拟环境并联网安装 `requests` 与 `Pillow`。
   - 看到“配对令牌”说明本机服务已启动。保留这个窗口运行。
4. 在 Chrome 打开 `chrome://extensions/`，开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择本项目的 **`extension` 文件夹**，不是项目根目录。
5. 点击新扩展图标，将本机窗口中的令牌粘贴到控制台，点击“连接本机”。
6. 正常登录米画师，先用一件作品试用，再添加一个画师主页。**不再需要勾选许可确认**，只保留非阻塞使用提示；请自行遵守作品许可与站点规则。也可以使用官网右下角的新面板提交当前页面。
7. 在新版本验证稳定前，**先暂停并禁用旧版画页存档扩展**，避免两套采集器同时请求网站。不要卸载或清理旧扩展的数据。

服务固定使用 `http://127.0.0.1:47653`。只监听本机，不需要开放 Windows 防火墙的公网访问；不要把端口转发到公网。如果安全软件阻止回环连接，应仅允许 Python / Chrome 在本机回环地址通信。页面预览不能代替实际加载扩展。

## 2. 日常使用

### 收集并下载

- 支持画师主页 `/users/...`、`/profiles/数字ID` 和详情 `/artworks/数字ID`。
- 默认 **3 路图片下载**，最大 4 路；页面导航共用至少 2 秒的节流。
- 链接发现、详情解析、图片下载相互衔接。无需等主页全部扫描完成，已经解析的图片即可开始下载。
- 两个后台标签页分别负责列表与详情；不滚动或跳转你原来的网页。
- 图片写入 `data/images`，按内容 SHA-256 命名并去重。控制台显示各任务的发现、解析、保存数量，三者不混为一谈。
- 点击“导出已完成图片 ZIP”，会在 `data/exports` 生成当前快照。包内按作品 ID 分类，并附 `manifest.json` 来源清单。
- ZIP 不会自动生成，也不会等待整批结束。如果后来又下载了图片，需要再次导出新快照。
- “增量扫描新作品”会从主页重新发现，按任务内的作品 URL 去重，**不是依赖未验证的站点分页 API**。

### 仅解析直链

选择“只收集图片直链”。解析结果仍落盘，不发起图片下载；在控制台导出 TXT。直链可能过期、限制外部访问，不能等同于已保存文件。

### 暂停、异常与继续

| 场景 | 当前行为 |
|---|---|
| 关闭浮层或控制台 | 不停止采集和本机下载 |
| Chrome Service Worker 被回收 | 通过已提交检查点及 Chrome alarms 重新调度；名义检查周期 1 分钟，不是浏览器调度时效保证 |
| 关闭 Chrome | 需要网页解析的部分等待浏览器；已提交本机的图片下载继续 |
| 关闭本机程序 | 下载停止；重新启动后未完成记录重新入队 |
| 普通网络错误 / 服务端暂时异常 | 单图最多 4 次尝试，指数退避并加少量抖动；失败不阻塞其他作品 |
| 单件详情无法解析 | 最多 3 次尝试，之后列入失败项，其他详情继续 |
| 扫描只得到部分结果 | 标记“部分收集”，已确认作品继续下载；可“重新扫描补齐” |
| 页面登录/验证提示、主文档 401/403、页面或图片 429 | 保留进度并进入访问暂停；尊重 Retry-After，人工检查后继续 |
| 单张图片 401/403 | 仅该图片标记待检查，不无限重试；检查官网后可“重新解析失败图片链接” |
| 点击“暂停任务” | 停止后续调度；已经在途的页面操作或下载可能完成一个检查点 |
| 关闭自动任务标签页 | 后续调度会尝试重建；正在进行的无链接卡片解析可能变为未解决项，需重新扫描补齐 |

如果扫描部分完成，界面不会把“已保存 12 张”说成“已完整保存画师 91 件作品”。网站标示总数可能包括不可见作品，仍须核对来源。

## 3. 续传与文件完整性

- 下载写入 `.part` 临时文件，不把未完成图片当作成功。
- 有稳定 ETag 或 Last-Modified 时使用 `Range` + `If-Range`。
- `206` 必须校验 `Content-Range` 的起点、终点、总长以及实体标识。
- 请求续传却收到 `200` 时清空旧暂存，从头写入，绝不拼接旧文件。
- `416` 清除不匹配暂存，有限次重试。没有可靠实体标识时从头重下。
- 检查传输长度、MIME、真实图片格式、尺寸与解码，再计算 SHA-256；同卷原子移动后才记录成功。
- 已完成相同 URL 的图片在本地文件仍通过 SHA-256 校验时可以直接复用；正在同时下载的相同 URL 仍可能产生少量重复流量，最终内容去重。
- 小图片的续传价值有限，队列恢复及不重复解析通常更重要。

## 4. 数据与备份

```text
data/
  archive.sqlite3       SQLite 持久任务与元数据（WAL 模式）
  archive.sqlite3-wal   运行期间可能存在
  archive.sqlite3-shm   运行期间可能存在
  pairing-token.txt     本机令牌，请勿公开
  engine.lock           防止同一数据目录重复启动
  parts/                未完成图片暂存
  images/               已验证的内容寻址图片
  exports/              ZIP / TXT 导出
```

**备份前先正常退出本机程序，再复制整个 `data` 目录。** 不要只复制正在运行的 SQLite 主文件、忽略 WAL。勿删除 `parts` 来“加速”，它是续传的基础。

这是独立混合版，没有自动迁移旧扩展 IndexedDB，也不自动继承旧下载的完成记录。请先在旧工作台保存 ZIP 暂存并导出来源/任务清单；旧文件原样保留。如果需要精确迁移已有任务，应另做显式迁移工具，不能直接覆盖旧数据库。

重新配对：正常退出程序，删除 `data/pairing-token.txt` 后重启，再在扩展控制台输入新令牌。扩展令牌只保存在受信任扩展上下文可访问的本地存储中。

## 5. 安全与限制

- 不导出 Cookie，不复制小红书签名或接口，不绕过验证码、登录或付费权限。
- 本机 API 使用随机令牌 + 已配对扩展标识 + Host 校验；兼容扩展 GET 不携带 Origin，有 Origin 时仍严格校验；官网 JavaScript 不能直接访问本机控制 API。
- 图片只接受米画师白名单 HTTPS 域名，逐跳检查重定向；TLS 校验保持开启。
- 本机下载不继承浏览器 Cookie，也不自动使用环境代理。若 CDN 必须依赖额外登录信息，会明确失败，不能承诺所有直链都可外部下载。
- 延续原 scanner 的过滤：不是所有网页图片都视为作品；小图、头像、推荐区图片会被排除。仅提取可见 DOM，不声称获得原始上传文件。
- 单图 128 MiB、3200 万像素、单边 16384；最多 30 个详情候选；单任务最多 5000 件作品，扫描有轮次与检查点大小限制。
- 待处理任务界面最多显示最近 100 个任务。无自动清理和删除功能；`parts` 中历史失败暂存可能占空间，应停机备份后再人工整理。
- 已验证真实 Chromium 的配对、任务提交和控制台关闭重开；当前未在 Windows 运行启动脚本，未完成 Chrome 系统级生命周期及米画师实站验收；这也是版本标记为 **preview** 的原因。
- 尊重站点规则与作品许可，不应用于未授权批量复制或再发布。

## 6. 开发与验证

```bash
python -m pip install -r native/requirements.txt
python -m unittest discover -s tests -v
node --test tests/worker.test.cjs
python native/server.py
```

Node 仅用于开发测试；运行扩展 + 本机引擎不需要安装 Node。

命令行可指定数据目录和图片并发：

```bat
.venv\Scripts\python.exe native\server.py --data D:\ArchiveData --workers 3
```

若修改端口，必须同时修改扩展 `hybrid-worker.js` 的 `BASE` 与 manifest 中 CSP 的 `connect-src`，然后重新加载扩展。普通使用无需改端口。
