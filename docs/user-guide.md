# 画页存档使用指南

把获授权的米画师作品和来源整理到自己的电脑。使用扩展不需要安装 Python 或 Node.js。

## 第一次安装

1. 下载本项目打包好的扩展 ZIP，完整解压到一个固定文件夹。
2. Chrome 打开 `chrome://extensions`；Edge 打开 `edge://extensions`。
3. 开启“开发者模式”，点击“加载已解压的扩展程序”或“加载未打包的扩展程序”。
4. 选择直接包含 `manifest.json` 的那一层文件夹。不要选 ZIP 虚拟目录，也不要选 JSON 文件本身。
5. 点击浏览器工具栏中的画页存档图标，打开工作台。安装前已打开的官网页面需要刷新。

如果你拿到的是整个 GitHub 源码仓库，请加载其中的 `extension/` 文件夹，不是仓库最外层。

## 推荐：留在官网，用浮动面板后台整理

0.4.0 的入口是页面右侧小图标，不再固定挡在左下方客服区域。

1. 在已获许可的画师主页，点击右侧画页存档图标，勾选本次许可确认。
2. 选择“后台收集作品链接”，或者熟悉流程后选择“后台收集并下载 ZIP”。工作台不存在时会在非活动标签页创建，不主动切换你的当前标签页。
3. 收起面板继续浏览。再次展开可看进度或停止；完成后点“打开工作台”查看队列、来源或下载文件。

可以拖动小图标或面板顶端的点阵把手；位置会在本机记住。支持收起、Esc 关闭、“重置位置”和“本页隐藏”（刷新恢复）。窄窗口中面板会限制在视口内。点击页面其他地方只收起面板，不把输入焦点拉回按钮。

后台收集沿用工作台的速度与作品上限，默认 2 秒、并发 2、最多 500 件。ZIP 入口明确切换为 ZIP 保存，不会因为旧设置是逐张模式而悄悄改变按钮含义。一次仅运行一轮任务，已有任务或未保存缓冲时需先处理。

“后台”是**独立任务标签页加工作台**，不是浏览器关闭后也运行的系统服务。不要关闭工作台或任务页。浏览器省电、后台节流、休眠、网站仅在前台加载的列表可能使任务变慢或停止。工具不主动滚动或跳转你正在浏览的原页面，但网站自身弹窗和浏览器“询问保存位置”仍可能打断操作，不能保证所有网页都完全无感。

只得到部分结果时，后台流程会保留队列，**不会弹确认框后擅自下载，也不会自动下载部分结果**。需要到工作台核对范围后手动下载。

### 像滚动脚本一样批量收集，具体怎么做？

先在独立任务页分段滚动，把页面已经提供的作品链接和公开卡片属性批量收集起来；这一阶段不打开详情。只有没有详情链接的卡片，才用正常点击解析，且只操作任务页。随后按本轮范围读取详情图、去重和分卷下载。

因此，直接暴露作品链接的主页可以更少跳转；但只有缩略图的页面仍可能需要详情解析。不能只从缩略图推算原稿地址，也不保证特殊虚拟列表能够收全。

### 想把图片直链交给其他下载工具？

有两种路径：

- 浮动面板展开“只要图片直链？”，点“后台收集并解析直链”。完成后打开工作台，展开“直链下载工具（可选）”，导出 TXT。
- 已有作品队列时，在工作台展开“直链下载工具（可选）”，点“批量解析图片直链”，再导出 TXT。勾选任务时只解析所选待处理项，未勾选时解析待处理队列，仍遵守本轮数量上限。

解析模式只取得详情展示图地址，不把图片文件保存到磁盘；**网站正常展示图片仍会产生图片网络流量**，不是零流量模式。已解析记录可以复用；失败项不会自动重试。

“导出全部已解析直链 TXT”包含整个队列中已预览、已下载或导入记录里的允许域名图片 URL，并去重；不是只导出当前筛选页，也不包含尚未解析的作品。不会导出已识别的缩略图地址。若要更精确的逐作品对应关系，请用完整来源 JSON。

直链可能过期、有防外链限制或需要正常浏览器请求环境，不能保证复制到任意工具都能下载。本工具不为外部下载器复制 Cookie、补造签名或绕过限制。省心使用仍建议内置 ZIP 下载。

## 普通用户只需三步

1. 在工作台顶部粘贴画师主页、作品链接或分享文字。无需先判断链接是哪种类型。
2. 确认本次作品获取和使用许可，然后点击“收集”。默认只收集链接，给你检查的机会。
3. 在队列中预览一件作品，确认图片内容与尺寸，再点击“下载待处理作品”。保存后点“打开下载文件夹”。

如果已经熟悉流程，可勾选“收集后直接下载”。主页直达流程只处理该次主页收集到的待处理作品；多条作品直达流程只处理本次粘贴的链接，不会顺手下载队列中其他未选择的旧任务。

需要登录或验证码时，只在官网自行处理。工具不需要你提供密码、验证码或 Cookie。

## 用哪个预设？

- **省心推荐**：页面间隔 2 秒，最多 2 个下载任务，约 128 MB 一卷。适合先尝试。
- **慢速轻量**：页面间隔 5 秒，最多 1 个下载任务，约 64 MB 一卷。适合配置较低或希望减少请求的电脑。
- **较快处理**：页面间隔 1 秒，最多 3 个下载任务，约 128 MB 一卷。可能更容易遇到网站限制，请按实际许可和网站状态决定是否使用。

预设不会压缩、裁切或降低图片分辨率，也不能保证账号不受限制。点击“显示高级设置”可以单独修改参数；工具会把非预设组合显示为“自定义”。

## ZIP 和逐张下载有什么区别？

- **打包为 ZIP**：将图片及来源清单一起保存，按图片内容哈希去重；图片不重新编码。默认按约 128 MB 图片数据分卷。
- **逐张下载**：通过浏览器原生下载接口保存单张图片，按成功图片 URL 去重，不进行内容哈希去重。

ZIP 直连如果被拒绝，工具会停止。先检查官网，必要时手动改成逐张下载，然后重置未完成项；不会自动换方式重试。

ZIP 阈值不等于浏览器总内存占用，解码和网页仍占用内存。单张最多 40 MB；ZIP 在解码前检查图片头，最多 3200 万像素、单边 16384，随后在单个 Worker 中串行缩小验证。保存的仍是原响应字节，不重新编码。ZIP 支持可安全识别的 JPEG / PNG / WebP / GIF，AVIF 或无法预检的文件会明确停止，可人工检查后选择原生下载；不会自动切换。

## 找到图片后怎么查看？

- “打开下载文件夹”：打开浏览器默认的下载目录。
- “定位最近文件”：尝试定位当前浏览器能确认属于项目记录的最近文件；旧记录导入或文件被移动时可能无法定位。
- 浏览器可能按自己的下载设置弹出保存确认或重命名文件；请以下载列表为准。
- ZIP 内的 `manifest.json` 是图片来源清单。用于恢复工作台的文件应通过“备份任务与来源”单独导出。

## 队列多了怎么整理？

- 使用“待处理 / 已完成 / 需检查”筛选。
- 搜索作品编号、画师名或链接。
- 每页可显示 25、50 或 100 件，不再只显示固定的前 250 件。
- 勾选部分待处理项后，“下载”只处理所选；没有勾选时，处理全部待处理项，仍受本轮上限约束。
- “重置”只让失败项重新进入等待状态，不会立即发起请求。
- “移除”只移除该项记录，不删除本地文件，但会丢失相应的去重依据。需要保留来源时请先备份。

## 网站提示 403、429、登录或验证

工作台会给出通俗提示和“查看任务网页”入口。登录不一定能解决 403；如果官网仍拒绝访问，请停止请求并确认平台允许的获取方式，不要反复点重试。

网站恢复后，你可以手动重置未完成项，再开始。本工具不提供代理轮换、账号轮换或验证码绕过。

## 为什么只收集到一部分？

主页收集依赖普通链接、常规卡片导航和网页滚动加载。特殊图集、虚拟列表、异步弹窗、筛选条件、访问权限、网络问题或页面改版可能影响结果。

高级设置中的作品上限默认 500，可设 1–1000；达到上限会报告部分结果。页面标示数量也不是绝对的全量证明。请检查“收集结果”和运行记录，不把部分结果误认为全部。

工具只识别已经渲染的候选图片，不保证下载轮播中尚未展示的所有附件。候选图也可能误选，建议每个新页面类型先预览。

## 停止后会丢图片吗？

已保存的文件不受影响。“停止本轮”停止后续调度，并尝试取消未完成请求和下载，不会控制官网自身所有后台请求。

**0.6.0 会将验证完成的图片与来源一起提交到本地数据库。** 关闭后重开工作台，可以点击“保存暂存图片 ZIP”，不需要重新采集或重新勾选网络采集许可。尚在请求或验证、未提交完成的图片不算可恢复；其临时输入在重开时清理。不要用“删除本地暂存”代替停止，它会永久删除未保存的暂存图片。

若提示“保存结果未确认”，先查看浏览器下载列表和保存目录，再点击“核对下载结果 / 允许重试”。能严格匹配的成功下载会恢复记录；历史缺失或无法判断时不会自动重新保存。只有你明确允许才可再次保存，可能产生重复文件。

超过 90 秒的执行间隔、冻结或明显时钟跳变会停止本轮。恢复后先处理暂存，再检查失败项、重置并手动开始。浏览器关闭或系统睡眠时不会继续采集。

清除扩展数据、另装一份扩展或卸载不会迁移暂存；JSON 备份只含记录，不含图片。更新、清理数据前请先把暂存保存为 ZIP。

重开后，工具会检查可追溯的浏览器下载记录。无法确认完成的项会保留为需检查状态，不会谎报成功。

## 更新与备份

1. 先在旧版点击“备份任务与来源”（旧版叫“导出来源清单”）。
2. 若希望保留开发版 ID 和本地记录，可用新版文件覆盖原来加载的同一路径，再到扩展管理页点击“重新加载”。
3. 如果换了文件夹，新开发版 ID 可能不同。停用旧版，在新版的“从已打开的网页选择 / 导入旧记录”中导入旧 JSON。
4. 刷新官网页面并重新打开工作台，避免旧按钮残留。

支持导入旧版工作台导出的任务 JSON；导入成功记录表示你确认对应文件仍在电脑中，工具不会读取或验证旧本地文件。不要把 ZIP 内的图片清单当成工作台备份。

记录受浏览器本地存储空间限制，长期使用应定期导出归档。清空或卸载会失去未导出的记录，通常不会删除下载目录中的文件。

## 反馈问题，怎样不泄露作品资料？

点击顶部“诊断信息”。诊断只含版本、粗略系统环境、数量、设置参数和错误类别，不含作品链接、画师名、图片、授权备注、完整日志或本地路径。

你可以复制或保存诊断 JSON，工具不会自动上传。如果复制被浏览器阻止，会选中文字，按 Ctrl / ⌘ + C 即可。提交 GitHub Issue 前仍请自行检查；不要发送密码、Cookie、验证码或未授权公开的图片。

截图和完整运行日志可能包含私人作品信息，请先遮挡。诊断导出与完整任务备份不同，后者确实包含来源链接和备注。


## 扫描停在第一件作品，提示历史记录或页面跳转怎么办？

这是旧版可能触发的主页返回缺陷，不代表必须逐个“添加此作品”，也不能据此认定没有登录。0.3.1 会先保留已发现链接，再恢复主页；若浏览器后退失败，只尝试一次原地址恢复。遇到真正登录验证或 HTTP 401 / 403 / 429 仍停止。

更新前保存旧版尚在内存中的图片并导出任务备份；不要卸载原扩展。覆盖同一加载目录后重新加载扩展，0.6.0 会一次性迁移旧记录，迁移事务成功前保留原数据。更新后关闭旧工作台、重新打开，并刷新官网主页；如果另装了一份扩展，暂时禁用旧版，避免点到旧浮动按钮。新版顶部应显示 **0.6.0**。

粘贴一个主页地址、确认许可，然后点“收集这个主页的作品”。已经粘贴地址时，无需再点“使用所选页面”。收集成功后队列会逐步增加作品，不需要手动逐个添加。

若仍失败，请停止重复尝试，反馈显示的版本、扫描结果和原始错误。优先使用诊断信息；补充截图前遮盖不希望公开的画师、路径及私人内容。不要发送 Cookie 或账号密码。


## 遇到访问保护暂停怎么办？

任务页或 ZIP 直连出现 401 / 403 / 429，或页面出现已识别的登录验证提示时，会记录本地暂停状态。重开工作台不会自动清除；浮动入口也会提示到工作台处理。

429 会参考服务器 `Retry-After`（秒数或日期），至少等待 60 秒；没有可用字段时也是至少 60 秒。倒计时结束**不会自动请求**。先在官网检查，再点“我已检查官网，解除暂停”，之后仍需手动重置失败任务并开始。原生下载出现明确的拒绝/未授权错误时也会进入人工解除的保护暂停，但它不保证能取得每次原生请求的 HTTP 状态和 Retry-After。

这不是“防封号”承诺，也不意味着等待 60 秒后网站一定允许访问。仍被拒绝时应停止使用并确认许可，不要连续解除后重试。已经取得的 ZIP 缓冲可在暂停状态下手动保存，不需要重新请求网站或重新勾选网络采集许可。

## 已解析直链会不会反复读取？

预览、下载和直链解析可复用 10 分钟内的就绪候选，减少重复打开详情页。候选复用不保证地址时效；遇到错误检查后“重置未完成项”会清除候选缓存，下一次手动操作再读取。导入备份现在会保留格式有效的候选和观察时间；过期记录需要重新读取。

## 提示本地记录保存失败或初始化失败

- 保存失败时会显示醒目提示。不要直接关闭工作台，先用“备份任务与来源”保存内存中的资料，再检查磁盘与浏览器存储空间。不要直接清除扩展数据，否则会删掉图片暂存。JSON 只备份记录，不含图片。
- 如果记录结构异常而无法初始化，工具不会用空白队列覆盖原记录。使用“导出原始恢复副本”先保存数据，再反馈问题；副本可能含私人链接和备注，不应直接公开。
- 导入时无效任务会跳过并报告数量，超过 5000 件或合并后超过上限会拒绝，不静默截掉剩余任务。没有有效成功图片记录的任务不会仅凭 `done` 字段被当成已下载。
- 导入的成功记录仍可按用户确认用于去重，但不会拿导入的下载编号直接定位或取消本机文件。原生记录恢复需核对 URL 和文件名，新 ZIP 恢复需核对本次下载来源；无法确认就标记未确认，不触碰无关下载。

## 为什么新版不跟随 ZIP 图片重定向？

为了避免先请求到未经确认的地址再报错，ZIP 直连使用拒绝重定向策略。页面给出的图片地址若发生跳转，工具会停止该请求，不会猜测新地址或自动切换下载方式。原生下载由浏览器处理，网络控制粒度弱于 ZIP 模式；实际原生请求跳转和响应头不属于全部可控范围。
