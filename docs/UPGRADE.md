# 从 Hybrid 0.7.1 升级

## 推荐：新项目目录 + 保留整个旧 data

1. 在旧控制台暂停任务，然后退出旧 Python 窗口。
2. 在 `chrome://extensions` 禁用或移除旧“画页存档 · Hybrid”扩展。关闭旧任务专用标签页和 `hybrid.html`。
3. **完整备份旧项目的 `data` 文件夹**。等待程序退出后再复制，不能只复制一个正在使用中的 SQLite 主文件。
4. 解压新 `MHS-Downloader` 项目，将整个旧 `data` 放入新项目根目录。
5. 双击新版 `START-WINDOWS.bat`。新目录可以重新创建 `.venv`；不必复制失效的虚拟环境，也不必重装已可用的 Python 3.12。
6. Chrome 加载新 `extension`，刷新米画师网页，在 MHS 浮动面板中配对。
7. 进入任务页，核对历史任务来源和数量限制。选择“继续”，或展开“更多操作与任务设置”后“保存设置并继续”。

新程序启动时所有旧活动任务都会变成暂停。这样保留历史，但不会因粘贴令牌而突然继续某个旧目标。

## 不想搬动大量图片

可让新程序直接使用已有数据目录。在 CMD 中进入新项目后：

```bat
set "MHS_DATA=D:\你的旧项目\data"
START-WINDOWS.bat
```

该设置只在当前终端生效。若以后双击 BAT 也要使用同一目录，可在 BAT 的 `setlocal` 后增加一行 `set "MHS_DATA=实际路径"`。不要让两个版本同时打开同一数据目录。

## 保留哪些内容

```text
data/
  archive.sqlite3        任务、作品、文件、导出历史
  archive.sqlite3-wal    若退出后仍存在，整目录一并保留
  archive.sqlite3-shm    若存在，整目录一并保留
  pairing-token.txt      本机令牌；不要发给他人
  images/                已完成图片，按内容哈希存放
  parts/                 部分下载及续传数据
  exports/               既有导出文件
```

迁移首次运行会在改表前用 SQLite backup API 写入 `archive.pre-0.8.0.sqlite3`。已存在时不覆盖；后续启动不重复创建。数据库备份不包含图片，也不替代整个 data 的备份。

旧版没有限量参数，升级后为每项补上默认 100 幅 / 100 张。**旧数据不会因此删除**；如果历史已超过这个数量，应在任务设置中将上限提高到不少于现有数量，或设为 0 后再继续。0 仍有安全上限，已有更多记录不被截断删除。

## 可原目录覆盖，但注意残留扩展

也可备份后，在原项目位置替换 `native`、整个 `extension`、BAT 和文档，保留 `data`。请替换整个扩展目录，而不是混杂新旧脚本；重新加载扩展并刷新网页。新版清单只加载 `worker.js`、`content.js` 和页内 `panel.html`。

不要继续使用旧 `hybrid.html`。新版 API 协议为 3，采集结果必须带任务 revision；0.7.1 浏览器端不应与 0.8.0 本机端混用。

## 排错

- **看到空任务列表**：先核对连接页的“保存位置”。很可能打开了新建的空 data，而不是旧 data；不要重复采集之前先处理目录问题。
- **端口 47653 占用**：退出旧 Python 窗口。不要随机改服务端端口，成品扩展固定使用 47653。
- **令牌正确仍失败**：确认运行的是 0.8.0；重新加载扩展并刷新米画师页面；检查浏览器本地网络权限。
- **旧 `.venv` 失效**：关闭程序，仅将 `.venv` 改名，再启动；不要删除 data。
- **恢复旧版本**：先停掉新版，再用完整旧备份恢复到另一目录。不要直接把旧版本写回已经迁移的数据库并假定所有新状态都兼容。

本版交付 ZIP 不包含任何用户 data、令牌、Cookie、浏览器配置或虚拟环境。
