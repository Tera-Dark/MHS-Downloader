## 测试过程中修正的问题

- 不声明广泛 `tabs` 权限时，按扩展页 URL 查询工作台可能返回空列表，导致停止入口错误地认为工作台已关闭。改为会话内登记工作台 ID，复用、启动和停止均按登记定位；未增加权限。
- 窄视口右侧面板可能溢出，改为按实际视口与面板尺寸约束位置。
- 测试数据需要足够初始内容才能产生滚动事件；修正模拟列表初始批次，同时重置测试遗留的作品上限。没有为让测试通过而放宽发行上限或站点停止规则。

## 不能据此作出的保证

- 不是该真实画师 91 件作品已经收集或下载完毕的证明；此前实站 403 后没有重放请求。
- 不是 Windows / Edge 所有版本、所有米画师布局或登录状态的验证。
- “后台”是浏览器内独立标签页，不是关闭浏览器后仍可运行的系统服务。后台节流、内存回收、休眠和网站前台可见性判断可能影响执行。
- 工具不主动操作原页面，但网站异步弹窗或系统下载位置提示仍可能打断浏览；不保证任意网页都绝不抢焦点。
- 不保证虚拟列表、特殊图集或全部风控提示均兼容；不可恢复或部分结果需明确停止/报告。
- 直链来自详情展示图或导入记录，不是推测的原稿地址，可能过期或限制外部下载。直链解析仍会加载官网图片资源，不是零流量模式。
- 不是生产 64/128/256 MB、多小时任务的内存压力认证；未增加 Cookie、全网或剪贴板等权限。

真实页面小批量验收应在持有许可的用户浏览器中进行，遇到拒绝或验证需先停止处理。
