# 画页存档 0.6.0

Chrome / Edge 桌面扩展，Manifest V3。无需 Python、Node.js 或单独客户端。

## 升级与安装
1. **先保存旧版未保存图片，再导出来源清单。JSON 不含图片，不能迁移图片暂存。**
2. 新 ZIP 的根目录直接有 manifest.json。完整解压，不要在 ZIP 虚拟目录中加载。
3. 若想保留相同扩展 ID 和本地记录，可将新版文件覆盖到原来加载的同一路径，然后到 chrome://extensions 点该扩展“重新加载”。旧工作台应先关闭。
4. 如果改用新目录加载，通常会得到新的开发版扩展 ID。停用旧版，在新版“补充详情链接 / 导入任务”里导入旧版导出的 JSON。
5. Chrome：chrome://extensions；Edge：edge://extensions。开启开发者模式，加载包含 manifest.json 的解压目录。刷新官网页面，避免旧按钮残留。
6. 不要直接双击 manager.html。它必须在扩展环境运行。

## 现在的主要流程
1. 使用与扩展同一个浏览器配置，在米画师官网正常登录（如需要）。不向任何人发送密码、Cookie 或验证码。
2. 工作台填入 `/users/画师名` 或 `/profiles/数字ID` 主页链接，或选择一个已经打开的官网页。
3. 确认获取和使用许可。先选“扫描作品链接”，核对扫描数量与未解析卡片报告；也可选“扫描并下载”。
4. 推荐第一次只设 3–5 件，并先预览一件，确认不是推荐图或缩略图。确认后再放大到该画师的授权范围。
5. 默认页面间隔 2 秒、下载并发 2、本轮作品上限 500；可改为 1–120 秒、并发 1–3、作品 1–1000。间隔按页面导航起点计算，不是每张图额外睡眠 45 秒。
6. 默认“所有符合规则的详情候选图”。多图依赖页面实际渲染的 img 元素，不保证覆盖轮播里尚未展示的所有附件。可切换“仅最大的一张”。
7. ZIP 模式会自动分卷，卷内自带 manifest.json；请另点“导出任务 / 来源”保存可恢复的工作台记录。

## 扫描实现与完整性
- 有可见详情链接或明确 data-artwork-id 的卡片，直接读取链接。
- 没有链接的卡片，正常触发页面点击。同页跳转时记录 URL 并返回；同步调用 window.open 的卡片会临时捕获公开导航 URL，不打开多余窗口，点击返回后立即恢复原函数。它不读取站点内部应用状态或登录凭据。
- 自动滚动使网站正常加载后续列表；不重放 / 猜测内部 API，不破解签名。
- 遇到页面标示数量、连续到底无新增、作品上限、扫描轮次上限或连续卡片解析失败时会结束或报告部分结果。空白、异步弹窗、虚拟列表、特殊卡片、改版页面可能无法解析；未解析项保存在扫描报告中。
- 页面标示数量和 DOM 能见范围不是绝对的全量证明。筛选、删除作品、访问权限、登录状态或懒加载均可能影响结果。达到本轮上限时不要当成已扫描完全部。
- 本实现每次扫描从主页开始，自动跳过已入队的详情链接；不是精确恢复上次浏览器滚动位置。

## 两种下载方式
### ZIP（默认）
- 图片读取与页面扫描/读取分离，最多 3 个下载任务并发，每任务的多张图串行。
- 对页面实际提供的图片地址做匿名直连，复用浏览器正常缓存。不改地址，不去水印。
- 每张图最多 40 MB、单个请求最多 45 秒；下载按至多 1 MB 块暂存；解码前预检尺寸（3200 万像素 / 单边 16384），串行 Worker 缩小验证并增量计算 SHA-256 / CRC32。超过上限停止，不偷偷降低质量。
- 按内容哈希去重。相同内容只写一次，所有作品来源仍保留在清单中。
- 图片不重新编码，ZIP 使用 STORE（不压缩已压缩的图片），默认 128 MB 一卷，可选 64 / 128 / 256 MB。这是单卷图片数据阈值，ZIP 使用 Blob 引用组合，不创建整卷 Uint8Array；不是浏览器进程总内存上限；实际内存还包括解码、网络缓冲和浏览器页面。低内存电脑建议 64 MB、并发 1。
- 分卷里有该卷图片来源清单；正式成功状态以浏览器确认下载完成后的工作台清单为准。
- 若匿名直连被拒绝，停止，不自动切换模式重试。请在官网检查后，手动选择原生模式。
### 浏览器原生
- 使用 chrome.downloads 保存单张图片，不把全部图片缓存在工作台。
- 仅按成功的图片 URL 去重；不宣称进行内容哈希去重或验证画师原稿。
- 浏览器在文件重名时自动加序号，实际文件名保存在记录中。

## 停止与恢复
- “停止本轮”停止新调度、取消正在进行的扩展图片请求，并尝试取消未完成下载。它不会拦截米画师网页自身发出的全部后台请求。
- 已验证图片及来源通过同一 IndexedDB 事务提交，重开工作台可恢复。可以点击“保存暂存图片 ZIP”，或明确删除暂存。
- 关闭工作台停止执行，不删除已提交暂存。下载前先写请求日志；重开后按扩展、URL、时间与唯一文件名严格核对。历史缺失等不确定结果需人工确认，不自动重复下载。未完成输入块重开时清理。
- 已成功图片 URL / 哈希将跳过。失败项不会自动重试；人工检查后点“重置未完成项”。
- 导入旧成功记录意味着你确认这些文件仍在电脑中，工具无法根据导入记录读取、验证旧本地文件。
- 任务、来源和设置受浏览器本地存储容量限制。大量使用时定期导出并归档，避免无限累积。清空任务会清除相应去重依据，但不删除磁盘文件。

## 数据与权限
工具会在本机处理链接、画师标记、图片、尺寸、哈希、授权备注和日志，并向官网及图片域名发起功能请求。不上传给开发者，不读取 Cookie。完整说明见 privacy.html。

当前权限：storage、scripting、downloads、webRequest；域名仅 www.mihuashi.com 与 image-assets.mihuashi.com。不再申请 tabs 权限，不申请全网访问、debugger、cookies、webRequestBlocking 或 unlimitedStorage。

## 验证和实站边界
本地模拟测试覆盖直接链接、同页跳转、新窗口导航捕获、懒加载、ZIP 实际保存与哈希、原生下载、失败停止及记录恢复。分卷边界使用测试注入的小阈值检查；发行版本的 64 MB 下限未放开。

真实站点此前在测试环境返回过 403，工具停止了访问。当前版本的自动化验证以本地模拟页面为主，不应宣称已通过所有登录实站页面的验收。
