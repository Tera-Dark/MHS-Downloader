## 不能由这些测试推出什么

- **不是 Windows / Edge 全面实机认证。** Windows 文件管理器实际弹出、各 Edge 版本、系统剪贴板成功及失败路径未全部验证。
- **不是实站采集成功证明。** 此前真实主页列表请求返回 403 后已停止；本轮没有重放该请求。403 本身不能证明原因一定是未登录。
- **不是所有风控场景覆盖。** 代码对 401 / 403 / 429 和明确登录验证采取停止策略；本次独立浏览器场景覆盖 403、429 和登录提示，不声称完整覆盖所有站点错误或验证样式。
- **不是大容量压力测试。** 分卷测试只在测试运行时降低阈值；没有完成生产 64 / 128 / 256 MB、多小时任务的峰值内存压力测试。
- **不是所有网站布局兼容。** 模拟网页不代表特殊图集、虚拟列表、未渲染附件及以后改版。
- **不是原稿保证。** 下载目标仍为页面实际提供的 `detail_display` 详情展示图，不改写 CDN 后缀来猜更大文件。
- **不是 GitHub Actions 已在线跑过。** 已提供 CI 配置，本地检查通过；尚未创建远程仓库或推送。
