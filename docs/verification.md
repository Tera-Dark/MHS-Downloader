## 故障注入说明

- 403/429、跳转等由本地服务器真实响应，权限/下载归属场景使用测试替身，不触碰用户下载记录。
- IndexedDB 中止使用真实事务 abort；无发行测试后门。
- ID 缺口先实际完成浏览器下载，再悬停 API promise 并关闭工作台。Playwright 的 GUID 文件名改写会影响严格归属，因此这两个场景临时使用浏览器默认下载行为和临时 profile 下载目录，不放宽生产匹配规则。
- 休眠通过时钟基线注入长间隔，不是实际 Windows 系统休眠/断电实验。
- 大图检查证明尺寸预检、哈希和串行执行；未测出也未声称固定进程 RSS 上限。
- 分卷边界测试降低阈值，生产仍为 64/128/256 MB；不是多小时压力测试。
