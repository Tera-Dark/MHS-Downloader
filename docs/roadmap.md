# 维护路线

## 0.6.0 已完成

增量状态库、服务拆分、持久图片暂存、下载提交日志与不确定结果处理、解码前尺寸预检、串行 Worker 校验、Blob 引用式 ZIP、休眠保守停止，以及 5000 条队列和故障回归。详见 [架构](architecture.md) 与 [审查](audit-0.6.0.md)。

## 后续维护（不是让用户替代本轮实现）

- 持许可的 Windows Chrome / Edge 实站兼容验收；不在拒绝后反复请求网站。
- 不同浏览器版本、存储配额、操作系统断电/磁盘损坏与长时间运行的持续验证。
- 根据实际网页改版补充 DOM fixture；必要时增加格式预检，不以猜地址替代页面观察。
- 若以后需要更大的单卷或目录写入，再单独评估文件系统权限和流式落盘；当前无权限扩张。

不会加入账号/代理轮换、验证码绕过、自动无限重试或未声明的数据上传。
