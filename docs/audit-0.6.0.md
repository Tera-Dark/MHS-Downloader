## 更新时请这样做

1. **先在旧版保存未保存的图片，再导出任务与来源 JSON。** 0.5 的内存图片不会因为装了新版而凭空恢复。
2. 关闭旧工作台。把 0.6.0 文件覆盖到原来加载的固定目录，在扩展管理页点击重新加载；不要先卸载。
3. 重新打开工作台并刷新官网页面。顶部应显示 **0.6.0**。保留同一扩展 ID 时会自动迁移旧任务；迁移事务成功前不会删除旧副本。
4. 若更换目录得到新扩展 ID，导入 JSON 只能迁移记录，不能迁移尚未保存的图片。

建议先用少量获授权作品核对真实网页兼容性；这一步不是替代上面的自动化验包。

## 必须说清的边界

- 已提交的图片暂存可恢复；正在请求/验证而尚未提交的图片不算已取得。
- 清除扩展数据、卸载或浏览器存储损坏仍可能删除暂存；JSON 不含图片二进制。
- 下载记录不确定时不会自动重复保存。请先核对目录，只有明确允许后才可重试，可能出现重复文件。
- 浏览器关闭/系统睡眠时不继续执行任务；恢复后是保守停止，不是永在线服务。
- 浏览器解码器、Blob 管理和网页自身内存仍不受 JS 绝对控制。本版消除了应用层整图/整卷数组累积，未声称进程 RSS 有硬上限。
- ZIP 单张上限 40 MB、3200 万像素、单边 16384；无法安全预检的格式（包括 AVIF）会停止，可人工检查后选择原生下载，不会自动切换。
- 不增加权限、不绕过登录/风控、不保证不会限制账号。
