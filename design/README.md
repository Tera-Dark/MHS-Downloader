# 图标与视觉资源

## 概念

画作卡片收进档案盒：上半部分表达图片，下半部分表达本地保存。采用与工作台一致的深绿、纸白和柔橙，不依赖文字或细线表达功能。

- 主色：`#285441`
- 辅助绿：`#48765A`
- 浅绿：`#DDE8D1`
- 纸白：`#FFFCF1`
- 暖橙：`#E9A977`

`icon.svg` 为源文件。16 / 32 / 48 / 128 px 用于扩展，额外提供 19 / 38 / 64 / 96 / 256 / 512 / 1024 px 输出。预览图在 `docs/images/icon-sheet.png`。

## 重新生成

```bash
python -m pip install -r requirements-design.txt
python tools/render_icons.py
```

这只是开发工具；扩展运行时不安装图像库，也不调用外部图像服务。

提交图标调整时请核对 16 px 的识别度，以及深浅浏览器主题中的效果。预览图是桌面模拟背景，不代表对所有操作系统主题做过测试。

源码和这些原创设计资源使用仓库 MIT 许可。不包含真实画师作品；第三方下载内容不受这个许可覆盖。
